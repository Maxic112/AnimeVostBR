# API AnimeVost и разметка сайта

У AnimeVost нет публичной документации API. Ниже — то, что использует приложение, с форматами и
особенностями, подтверждёнными живыми запросами. Эталонные ответы для тестов лежат в
[`app/src/test/resources/fixtures`](../app/src/test/resources/fixtures); проверить текущее состояние API
можно скриптом [`tools/api_check.py`](../tools/api_check.py).

## JSON API

Базовый адрес: `https://api.animevost.org/v1`. Бэкенд — Flask/Werkzeug. POST-запросы принимают
только `application/x-www-form-urlencoded` (JSON-тело → HTTP 400).

| Запрос | Назначение |
|---|---|
| `GET /last?page=N&quantity=M` | Лента тайтлов в порядке обновления (весь каталог постранично) |
| `POST /playlist` (`id`) | Серии тайтла со ссылками на видео |
| `POST /info` (`id`) | Карточка тайтла |
| `POST /search` (`name`) | Поиск по названию |

### `GET /last`

- Параметры `page` и `quantity` нужны **оба**: без них возвращается один тайтл, с одним `page` — HTTP 500.
- `quantity` больше 40 не даёт больше 40 записей.
- Ответ: `{"state": {"status": "ok", "page": N, "count": <всего тайтлов>, ...}, "data": [ ... ]}`.

Поля элемента `data[]`:

| Поле | Тип | Описание |
|---|---|---|
| `id` | число | Постоянный идентификатор тайтла (news-id сайта) |
| `title` | строка | `Русское / English [1-5 из 12+] [6 серия - 8 ноября]` — служебные части в скобках |
| `description` | строка | Описание с HTML-тегами `<br>` |
| `genre` | строка | Жанры через «, » |
| `year`, `type`, `director` | строка | Год, тип («ТВ», «Полнометражный фильм»…), режиссёр |
| `urlImagePreview` | строка | Постер на `static.openni.ru` |
| `rating`, `votes` | число | `rating` — **сумма** оценок; средняя = `rating / votes` |
| `timer` | строка | Unix-время выхода следующей серии; `0` у завершённых тайтлов |
| `series` | строка | Python-словарь в одинарных кавычках: `{'1 серия':'747648616', ...}` — **не JSON** |

Значения в `series` — идентификаторы видеофайлов, ключи — названия серий (те же, что в плейлисте).

### `POST /playlist`

Ответ — массив без обёртки:

```json
[{"name": "1 серия",
  "hd": "http://video.animetop.info/720/747648616.mp4",
  "std": "http://video.animetop.info/747648616.mp4",
  "preview": "http://media.animetop.info/img/747648616.jpg"}]
```

- Поле SD-ссылки называется `std`, а не `sd`.
- Порядок массива — порядок серий. **Название не равно номеру**: встречаются «215-216 серия»,
  «492(1) серия», «1-40 серии», «ОВА 1», «Фильм». Поэтому серия идентифицируется позицией в массиве.

### `POST /info`

Ответ: `{"state": {...}, "data": [<элемент в формате /last>]}`.

### `POST /search`

- Параметр — `name`; поиск по подстроке русского и английского названия без учёта регистра.
- Не более 50 результатов, `page`/`quantity` игнорируются.
- Ничего не найдено → HTTP 404 `{"error": "Ничего не найдено"}`.
- Знаки препинания ломают поиск (`Ван-Пис` → 404, `ван пис` → результаты).
- С любым другим именем параметра (`search`, `query`, `story`) или без него сервер возвращает один и
  тот же список из 50 тайтлов, не связанный с запросом.

## Видео и изображения

| Хост | Содержимое | Особенности |
|---|---|---|
| `video.animetop.info` | MP4 (H.264): `/720/<id>.mp4` — HD, `/<id>.mp4` — SD | Поддерживается `Range`; работает по HTTP и HTTPS. У части старых серий HD-файл отсутствует (404). Full HD здесь нет |
| `fhd.trn.su` | MP4: `/1080/<id>.mp4` — Full HD | Только HTTPS, поддерживается `Range`. Ссылку выдаёт страница плеера, см. ниже |
| `media.animetop.info/img/<id>.jpg` | Кадры-превью серий | |
| `static.openni.ru` | Постеры | HTTPS-сертификат просрочен, приложение загружает постеры по HTTP |

### Full HD

В API Full HD нет: поля `hd` и `std` — это 720p и 480p. Ссылку выдаёт страница плеера сайта
`/frame5.php?play=<id видео>&old=1` (есть и на зеркале, тема от User-Agent не зависит):

```js
"file":"[SD (480p)]<ссылки>,[HD (720р)]<ссылки>,[FHD (1080p)]https://fhd.trn.su/1080/<id>.mp4?md5=…&time=… or <запасные>",
```

- Запасные ссылки разделены ` or `; они ведут на файлы меньшего качества, поэтому нужна ссылка с `/1080/`.
- `time` — срок действия ссылки, примерно 3 часа от запроса.
- Метка `[FHD (1080p)]` есть, только если файл существует. Проверено на 28 сериях: без метки файл отвечает
  404, с меткой — 200. Файла нет у части новых тайтлов и у ранних серий длинных тайтлов.
- На странице есть ещё запасной плеер (`res.trn.su`), собранный из кусков строки:
  `"file":"[SD (480p)]"+mlink+",[HD…,[FHD (1080p)]…"`. Там Full HD указан всегда, даже если файла нет.
- Файл Full HD примерно в 1,4–1,5 раза больше HD, но бывают исключения: у отдельных серий и фильмов — до 3–4,5 ГБ.
- Страница содержит IP-адрес клиента и токены, поэтому её нельзя сохранять в репозиторий как есть.

## Сайт и зеркало

Сайт работает на DataLife Engine. Основной домен — `animevost.org`, зеркало — `vN.vost.pw` (номер со
временем растёт). API на зеркале нет.

Где сайт сообщает текущий адрес зеркала:

1. старый адрес зеркала отвечает редиректом 301 на новый (`v13.vost.pw` → `v14.vost.pw`);
2. ссылка на главной `animevost.org/` и на странице `animevost.org/zerkalo.html`;
3. все ссылки в RSS зеркала (`/rss.xml`) ведут на его текущий адрес.

### Разметка для резервного режима

**Лента** — `/` и `/page/N/` (около 10 тайтлов на странице):

```html
<article class="post" style="background-image: url('/uploads/posts/2026-09/1790061699_1.jpg');">
  <span><a href="https://<сайт>/tip/tv/4032-<slug>.html"></a></span>
  <h2>Русское название / English title</h2>
  <div class="short-categori"><i>
    <a href=".../tip/tv/">ТВ</a>, <a href=".../god/2026/">2026</a>, <a href=".../zhanr/priklyucheniya/">Приключения</a>
  </i></div>
</article>
```

**Тайтл** — `/index.php?newsid=<id>` (slug не нужен):

- блок `.infoContent`: `<h3>` с названием, постер `<img>`, абзацы `<p><strong>Год выхода:</strong> 2026</p>`,
  «Жанр», «Тип», «Количество серий», «Режиссёр», «Описание»;
- скрипт плеера: `var data = {"1 серия":"747648616", ...};` — те же id видеофайлов, что в API, поэтому
  ссылки на видео строятся по шаблонам `video.animetop.info`;
- таймер следующей серии: `parseInt(<unix-время> - t)`.

**Поиск** — `/index.php?do=search&subaction=search&search_start=<страница>&story=<запрос>`
(полнотекстовый поиск DLE, используется, когда поиск API ничего не нашёл).

**Выборки каталога** — та же разметка `article.post`, что у ленты, по 10 тайтлов на странице:

| Путь | Значения |
|---|---|
| `/zhanr/<slug>/` | 27 жанров: `drama`, `komediya`, `boyevyye-iskusstva`, `fentezi`, … (полный список — `core/Catalog.kt`) |
| `/tip/<slug>/` | `tv`, `tv-speshl`, `ova`, `ona`, `polnometrazhnyy-film`, `korotkometrazhnyy-film`, `dunkhua` |
| `/god/<год>/` | 1971 … текущий год (до 1991 — только отдельные годы) |

Следующие страницы — `<путь>page/N/`; страница после последней отвечает **404**.

> Разметка `article.post` — мобильная тема сайта. Её сайт отдаёт на User-Agent приложения
> (`AnimeVostBR/… (Android; client)`); с браузерным User-Agent приходит десктопная тема
> (`div.shortstory`), которую парсер не разбирает.
